# Drawing automation

`drawing_auto.swp` is the runnable macro. `reference/drawing_auto.bas` is the
matching readable export and was statically reviewed for balanced procedures,
explicit declarations, and error-handler targets.

The older version-named upload was moved, without deletion, to
`../legacy/drawing-automation/`. It is nearly identical to this source but does
not carry the exported VBA module-name metadata and is not the source extracted
from the current binary.

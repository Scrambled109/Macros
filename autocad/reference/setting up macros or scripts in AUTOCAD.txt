To setup scripts or macros in autocad there are a couple of methods but heres the one im going over. 
Step 1 First go to the manage tab in autocad and click on load application in the applications section
Step 2 find the script or customfile or LISP file and select it and then select load
Step 3 IMPORTANT set this as a startup application if you dont do this youll have to do step 1 and 2 every time. To do this in the load/unload applications dialog box in the bottom right it says "startup suite" select contents then select add and select your file

TIP autocad sometimes doesn't really like shared drive especially when certain characters like "#" so to make sure it runs cleanly typically download the script to your computer and select it from there

Step 4 after you've done this type CUI in a open autocad drawing and hit enter
Step 5 in the bottom left box of the dialog box where it shows all the commands right click and select new command
Step 6 on the right name your command then in the Macro section after the ^C^C with no space the name of your file for example : "^C^CCOLORTOLAYER"
Step 7 hit apply and then if you want to add a keyboard short cut go in the top left box find keyboard shortcuts, expand it then expand shortcut keys and then drag your command from the bottom left box somewhere within the keyboard shortcuts. when you do this it should open a box in the top right but you might have to select it within the top left box once you do this in the top right set your keyboard shortcut (i like to use Shift + something as its typically not used) and hit apply.

After this you should be up and running
